# 무료 베이직 / 프리미엄 전환

## 보존 기준

개발 브랜치 `feat/elliptical-train-ride`, 업로드 기준 `4240465`. 기존 7종: 포근한 크리스마스 / 눈꽃 숲속 마을 / 종소리 작은 성당 / 달빛 겨울 궁전 / 진저브레드 마을 / 오로라 호수 마을 / 별빛 천문대. 이름·이미지·배치는 그대로 두고 이전 무료 3종도 프리미엄 이용권 대상으로 분류한다.

`tests/fixtures/premium-preservation.json`의 SHA-256으로 기존 이미지 전체와 Actors·선로·가림·조명·주행음·기적·음악·눈 소스의 변경 전 바이트 동일성을 검사한다. `appName`, SDK 3.9.0, 13초 기차 / 6바퀴 기적 / 기존 gain / 4패턴 / 눈 효과는 유지한다. 프리미엄 사진의 기존 합성 위치와 WebGL 스냅샷 경로도 유지한다.

## 베이직

- 사용자 PNG를 그대로 보존하며 중복 `.png.png` 확장자만 정리했다. 원본 무결성은 `tests/fixtures/basic-originals.json`으로 검사한다.
- 크리스마스 종탑집 / 눈사람 숲속집. 집과 받침대가 잘리지 않는 원본 비율, 화면용 960×1050 WebP와 선택용 320×350 WebP를 별도 제공한다. 프리미엄 이미지 재압축 없음.
- 베이직은 Actors / WebGL / 열차 / 주행음을 만들지 않는다. 선택된 베이직만 작은 2D 조명 캔버스를 소유하며, 숨김·광고·선택창에서는 멈춘다. 조명 좌표는 두 이미지에 각각 지정한다.
- 은은한 조명 / 반짝이는 조명 두 패턴. 원본의 기본 전구와 창문은 항상 따뜻한 상태로 남고 추가광만 변한다. 프리미엄 조명 상태와 분리 저장한다.
- 기존 눈 코드를 그대로 재사용한다. 기존 MusicPlayer를 사용하되 고요한 밤만 허용하고 이전·다음 버튼을 숨긴다. 프리미엄 곡에서 전환할 때 기존 소스를 정지하고 고요한 밤으로 동기화한다. 프리미엄으로 돌아오면 5곡 선택·4패턴·동작 버튼을 복원한다.
- 사진은 기존 1200×1560 PNG 경로를 사용한다. 베이직에만 원본 종횡비와 해당 조명 합성을 적용한다.

## 광고 / 이용권 / 시간

- 7종 각각 독립된 7일 영수증. 활성 이용권 누적 연장 없음. 광고 완료 보상 이벤트와 정상 종료가 모두 확인돼야 지급한다. 실패·취소·시간 초과에는 지급하지 않는다.
- 잠긴 마을은 선택창 → 정적 미리보기 / 명시적인 광고 버튼으로 연결한다. 미리보기만으로 실제 프리미엄 장면에 진입하지 않는다.
- 광고 그룹 ID 미설정 / 개발 모드 / 토스가 아닌 브라우저 / SDK 미지원 환경은 광고와 보상 지급을 차단한다. 배포 코드에 테스트 해제 스위치나 모의 보상 없음.
- SDK `Environment.getServerTime`으로 발급 시간을 확인하고, 세션에서는 서버 기준 시간 + 단조 시간 경과를 사용한다. SDK 서버 시간 확인 실패 시 새 이용권을 발급하지 않는다. 브라우저 대체 경로는 저장된 최고 시각보다 과거로 돌아가지 않는다.
- SDK `Storage.getItem/setItem`과 기존 브라우저 로컬 저장을 연결한다. 예전 특별 빌리지 영수증은 그대로 유지하고, 예전 공통 이용권이나 특별한 밤 영수증을 새 빌리지 보상으로 전환하지 않는다. 특별한 밤 UI·메뉴·적용 연결은 제거하되 공유 효과 소스는 보존한다.
- 만료 확인 시 무료 베이직 1로 돌아가고 프리미엄 음악·사진·동작을 정리한다. 단조 시계와 로컬 최고 시각은 완전한 변조 방지 수단이 아니다. 현재 영수증은 기기 로컬이며 계정 동기화·서명된 서버 이용권 검증은 없다.

## 검증과 한계

- `npm run build`: TypeScript, 전체 자동 테스트, 웹 빌드, 웹 산출물 검증. AIT는 생성하지 않는다.
- `scripts/check-basic-premium.mjs`: Chromium 320×640, 375×812, 430×932, 430×640. 베이직 2종, 2/4패턴 분리, 음악 1/5곡, 눈 토글·선택창 숨김, 9개 정적 카드, 웹 광고 차단, 7종 실제 WebGL 장면, 트리·열차 동작/정지/재개, PNG 생성/다운로드, 만료 시 무료 복귀, 콘솔·페이지 오류를 검사한다.
- 브라우저 테스트의 저장된 영수증 fixture는 해당 일회성 Playwright 컨텍스트에서만 주입하며 운영 코드의 광고 완료를 가장하지 않는다.
- 변경 전 웹 출력은 2,171,331바이트. 최종 웹 출력은 2,478,220바이트(약 14.13% 증가)이며 자동 테스트 46개가 통과했다. 원본 PNG는 저장소에 보존하지만 웹 출력에는 포함하지 않는다. 증가분의 대부분은 신규 WebP 4개다. 실제 최종 크기는 완료 보고와 `verify:web` 출력에 기록한다.
- 공식 개발자 가이드 도메인은 현재 환경의 CONNECT 정책으로 403 차단되었다. 설치된 공식 SDK 타입 선언을 확인했으며 최신 공식 앱 크기 제한값은 확인하지 못했다. 임의의 제한값을 가정하지 않는다.
- 실제 광고 그룹 ID는 비어 있다. 토스 실기기의 실제 광고 완료·취소·실패, 서버 시간 응답, SDK 저장 지속성, 네이티브 사진 저장과 실제 모바일 성능은 별도 검증이 필요하다. 소프트웨어 Chromium 검사는 실기기 60fps 보장이 아니다.
