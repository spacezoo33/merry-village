# 베이직 외곽의 어두운 잔상 보정

원인은 CSS `drop-shadow`나 원본 PNG의 투명 검정색이 아니라, 기존 SVG 집 윤곽이 실제 지붕·굴뚝·외벽보다 넓어 원본의 짙은 갈색 배경을 함께 남긴 것이었다. 집 마스크의 5px 페더도 이 배경을 외곽으로 번지게 했다.

`src/basic-art.ts`의 두 집 윤곽을 원본 색상 경계에 맞춰 보정하고, 집에만 0.65 원본 픽셀의 좁은 알파 경계를 적용했다. 원본 RGB 이미지, 장식/나무/조명, 받침대 및 아래 그림자의 기존 경로·그라디언트는 유지한다. 정상적인 건축물 내부 음영을 밝게 만들거나 이미지를 재생성·전체 블러 처리하지 않는다. 화면 및 PNG 촬영은 기존처럼 같은 마스크 함수를 사용한다. 런타임은 SVG 마스크만 사용하며 이미지 분석 도구나 새 의존성을 앱에 추가하지 않았다.

검증:

- TypeScript, 자동 테스트 47개, 웹 빌드 통과.
- `scripts/check-basic-shadow.mjs`: Chromium 320·375·430px, DPR 2에서 두 집의 전후 화면 및 지붕·굴뚝 확대를 확인. 화면 크기·위치는 동일하고 콘솔/페이지 오류 없음.
- 비교 기준 URI는 `BASELINE_MASKS_JSON`으로 검증 도구에만 제공한다. 375px 검사에서 두 집의 불필요한 어두운 경계 픽셀을 원본 좌표 기준 각각 26,237 / 29,081개 제외했다. y≥850의 받침대/아래 그림자 마스크 차이는 최대 0 / 1(255단계)로 유지됐다.
- 원본 베이직 PNG와 프리미엄 이미지/핵심 효과 36개 보존 SHA 검사를 유지한다. `main.ts`, `state.ts`, `native.ts`, `ad-session.ts`, `access-clock.ts`, `catalog.ts`, `style.css`, `basic-lights.ts`, `photo.ts`도 변경하지 않았다. 광고 문구·보상 7일 규칙·저장 로직 변경 없음.
- 기존 프리미엄 7종 브라우저 회귀와 무료 2곡/프리미엄 5곡, 조명 패턴, 눈, 만료 전환, 사진 저장 검사를 유지한다. 최종 베이직 사진도 별도 촬영해 외곽을 확인한다.

실제 토스 앱과 실기기 청감/성능은 이번 소프트웨어 Chromium 검증 범위가 아니다. ZIP/AIT 생성 및 main 병합 없음.
