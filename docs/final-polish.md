# 체감 개선 — 구현 범위와 실제 검증

## 조명

오른쪽 버튼으로 **전체 → 교차 → 랜덤 → 은은한 반짝임 → OFF → 전체**를 순환한다.
기본 설정은 은은한 반짝임이며 기존 저장값은 보존한다. 조명 팝업/선택창은 제거했다.
75개 트리 전구의 개별 발광과 비발광 몸체 밝기, 빌리지별 88개 건축 장식 전구를 직접 제어한다.
건축 전구는 처마·전면 장식줄·터널 아치의 원본 셀 좌표에 배치한다. 창문/가로등 중심은 제외한다.
전구의 작은 비발광 하우징과 발광 코어를 분리하며 OFF 시 장식 발광만 0이 된다.
배경 사진 자체의 창문·가로등과 기록된 빛은 유지된다. 전체 사진 밝기를 바꾸는 기능이 아니다.

실제 브라우저에서 동작/눈을 멈춘 동일 장면의 전체 점멸 밝은/어두운 프레임을 비교했다.
트리 영역 939px, 건축 장식 영역 1265px에서 RGB 평균 차이가 20 이상이었다.
실내 배경/원목 받침대 비교 영역의 변화는 0이었다.
측정 데이터는 [validation](validation/polish-light-pixels.json)에 보관했다. 전구 비발광 몸체도 함께 어두워지도록 보강한 상태로 측정했다.

## 소리

`audio-engine.ts`는 음악/종/기차/경적 4개 독립 버스를 최종 믹서로 모은다.
음악 일시정지는 음악과 종만, 동작 OFF는 기차와 경적만 정지한다. 백그라운드에서는 모두 정지한다.
최종 믹서에 헤드룸과 완만한 리미터를 두었다. 사용자 음량은 음악/종에 함께 적용한다.
기차 주행음은 18초당 64펄스이며 차량의 일시정지된 여정 시간으로 위상을 맞춘다.
0.65초의 출발 지연도 반영한다. 4펄스 버퍼를 오디오 장치가 끊김 없이 반복하며 렌더링 타이머에 의존하지 않는다.
경적은 운행 시간 기준 첫 27초, 이후 29/23/34/27초 간격이다. OFF 중에는 예약된 경적도 취소한다.

실제 Chromium 최종 버스를 MediaRecorder로 약 **42.78초 녹음**했다.
기본 음량에서 음악 RMS 약 .027–.031, 종 .014–.016, 기차 .008–.011이었다.
최대 음악 음량 구간을 포함한 전체 녹음을 PCM으로 디코딩한 피크는 **0.4630 (-6.69dBFS)**,
클리핑 샘플은 **0**이었다. 같은 브라우저의 OfflineAudioContext로 이전/새 주행음을 같은 필터 조건으로 렌더한 RMS 증가는 **15.59dB**였다.
수치는 [실제 버스 측정](validation/polish-live-audio.json), [주행음 비교](validation/polish-train-comparison.json), [녹음 통계](validation/polish-recording.json)에 있다.

이 결과는 **실제 오디오 출력 신호·녹음 검증**이다. 사람이 스피커/이어폰으로 직접 청취해
음색·선호도·청감상 충분한 볼륨을 평가했다고 주장하지 않는다. 토스 실기기/외부 스피커 청취는 미검증이다.
검사 스크립트는 `/tmp/merry-polish-live-mix.webm`을 생성한다. 재생해 청감 평가할 수 있다.

## 최종 목록과 미완료 곡

1. 고요한 밤: 기존 선율/템포 유지, 자체 합성 + 강화된 독립 종.
2. 징글벨: 기존 선율/템포 유지, 자체 합성 + 강화된 독립 종.
3. 기쁘다 구주 오셨네: 기존 선율/템포 유지, 자체 합성 + 강화된 독립 종.
4. **축하해요 크리스마스: 권리 근거 미확보로 비활성, 음표/음원 미포함.**
5. 오 크리스마스 트리: 이전 4번의 확인된 선율을 5번으로 이동해 기존 5번을 교체.

**무료 5곡 전체 재생은 미완료**다. 4번은 공개 코드에서 Traditional이라고 표기된 사실만 확인했다.
그 표기를 특정 악보/현대 편곡의 상업 이용 허락으로 해석하지 않았다. CPDL/Wikipedia 원문 접근은
네트워크 정책의 CONNECT 403으로 막혔다. 출처가 불명확한 MIDI/현대 편곡을 대신 사용하지 않는다.
이용 허락이 분명한 전통 단선율 원문/PD 근거를 확보한 뒤에만 활성화한다.
재생 가능한 4곡은 [음악 권리 문서](music-rights.md)의 자체 연주이며, 한국어 가사나 외부 상업 녹음물은 없다.
금지된 ‘창밖을 보라’/‘울면 안 돼’는 포함하지 않았다. 이전 4번 선택값은 오 크리스마스 트리(5번)로 이관한다.

## 눈과 디자인

기본 44→74개(+68%): 후경 24/중경 28/전경 22. 크기는 모든 층에서 1.75배.
전경은 큰 부드러운 눈, 후경은 작고 흐린 눈이며 각각 속도/좌우 흔들림이 다르다.
3초 이상 낮은 프레임이 계속되면 56 또는 44개로 줄이고 안정 상태가 15초 이어지면 한 단계씩 복구한다.
탭 숨김/움직임 줄이기/눈 OFF에서 모니터를 중단한다. 실제 CPU 압박 검사에서 밀도 감소를 확인한다.

건축물 원본을 흐리거나 축소하지 않았다. 원본 PNG들은 바이트 단위로 보존한다.
움직이는 트리/차량 밑에 따뜻한 접지 그림자, 눈 표면의 미세한 거칠기를 추가했다.
기존 6개 철도/터널 캘리브레이션과 실제 트리/열차 오브젝트를 유지한다. 사진에서는 현재 3D 포즈를 1200px로 별도 렌더해 저해상도 휴대폰 프레임을 확대하던 현상을 줄였다. 배경은 비율을 유지해 채운다.
완전한 건축 3D 모델이나 모든 오브젝트의 물리적 동적 그림자는 아니다.

특별한 밤 3종·이용권·사진 저장·공식 SDK/appName·Pages 워크플로는 유지한다. AIT는 만들지 않는다.

최신 집중 검사는 `node scripts/check-polish-browser.mjs`를 사용한다. 기존 `check-product-browser.mjs` 진입점은 빌리지마다 실제 두 바퀴를 추가로 운행하는 전체 철도 회귀 모드를 유지한다.
