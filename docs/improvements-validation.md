# 디자인·철도·소리 개선 검증

2026-10-31, Chromium 154, 로컬 GitHub Pages 하위 경로와 같은 `/merry-village/`에서 검증했다.
토스 실기기 GPU/네이티브 저장 테스트는 아니다. AIT는 생성하지 않는다.

- 실제 브라우저에서 무료/특별 6종 각각 36초 이상의 연속 주행(18초 × 2바퀴), 전면/터널 진입 캡처.
  각 마을의 선택 ID와 프로필을 함께 확인해 공통 경로를 다른 이름으로 검사하지 않는다.
- 320/375/430px, PC 1440px에서 가로 넘침 없음.
- 트리 37초, 기차 18초, 동시 OFF/ON 위치 연속성.
- 조명 전체/교차/랜덤/은은한 반짝임의 실제 전구 밝기 차이, 전원 OFF 시 발광 0, 마을 변경 후 패턴 유지.
- 눈 3레이어, 전원 OFF/ON, 움직임 줄이기와 탭 백그라운드 중단/복귀.
- 기차 오디오 시계의 진행·루프, 경적 재생 시점 29/23/34/27초 간격, 동작 OFF 시 소리 정지.
- 동작 OFF 중 음악 유지, 음악 일시정지 중 기차 소리 유지.
- 5곡의 서로 다른 실제 버퍼 길이와 비무음/정규화된 진폭 확인.
- 기존 특별한 밤 3종의 선택·미리보기·돌아가기 유지.
- 실제 PNG 다운로드: UI 없는 1200×1560 PNG, 현재 트리/열차 프레임 합성.

추가 자동 회귀 테스트는 빌리지별 좌표 투영·커플러 거리와 조명 연속성/저장,
음악용 공유 장치 시간이 흐르는 중에도 기차의 정지 시간이 경적 대기 시간에 섞이지 않는 경우를 검사한다.

`npm run build`는 TypeScript/자동 테스트/웹 빌드/웹 아티팩트 검증만 실행한다.
긴 브라우저 검사는 별도의 전용 Chromium 디버깅 세션(:9222)과 웹 서버가 필요하다:

```sh
npm run preview -- --port 4180
# 별도 터미널: 전용 Chromium을 --remote-debugging-port=9222 로 실행
PREVIEW_URL=http://127.0.0.1:4180/ node scripts/check-product-browser.mjs
```

검사 스크립트는 전용 테스트 탭을 열고 해당 로컬 페이지의 저장소를 초기화한다.
운영 미리보기 도메인을 PREVIEW_URL로 지정하지 않는다. 여러 소프트웨어 WebGL 탭을 동시에 켜지 않는다.
단위 테스트는 측정 좌표와 수학적 경로의 일치를 확인하며 원본 사진의 모든 픽셀 정확도를 보증하지는 않는다.
터널 건축물은 정적 플레이트이고 실시간 가림은 별도 월드 클리핑이다. 이 혼합 구조의 한계는 [철도 문서](rail-calibration.md)에 기록했다.
