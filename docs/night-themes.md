# 화면·기적·독립 특별한 밤

## 변경

- 기적 버스 gain만 0.70→0.49로 변경해 이전 대비 30% 추가 감소했다. 주행음 0.75, 음악 1, 마스터 0.9와 기존 덕킹은 유지한다. 파형·2.65초 길이·6/12/18바퀴 중앙 통과 판정은 바꾸지 않는다.
- 화면 최소 높이 100svh는 하단 메뉴 배치에 필요한 한 곳에서 유지하되, experience 안의 가용 높이를 마을·설명·플레이어 사이에 배분했다. 이미지를 확대하거나 잘라 여백을 없애지 않는다. 320/375/430px 및 짧고 긴 화면에 대응하고 작은 기기는 자연스러운 세로 스크롤을 허용한다.
- 동작·조명·눈 버튼의 시각적 ON/OFF 문자를 제거했다. 기존 터치 영역·aria-pressed·밝기/테두리 구분은 유지한다. 접근성 이름은 켜짐/꺼짐을 안내한다.
- 현재 저장소의 기본 3개 및 특별 4개 마을, 원본 이미지·철로·터널·조명 좌표·111개 작은 눈·5곡 반복·사진 기능을 유지한다.

## 특별한 밤

| ID | 이름 | 표현 |
|---|---|---|
| moonlight | 푸른 달빛의 밤 | 남색 하늘·푸른 달과 얕은 눈 반사 |
| shooting | 황금빛 별의 밤 | 금색 별의 느린 반짝임·트리 및 외부 광원 추가광 강화 |
| aurora | 오로라의 밤 | 청록/보라 그라디언트의 느린 움직임·색 반사 |

별도 대용량 마을 이미지는 추가하지 않았다. 선택 카드에는 현재 실제 선택한 마을의 기존 정적 썸네일과 CSS 미리보기를 사용한다. 장면의 원본 건물/창문은 유지하고 낮은 알파의 눈 반사 레이어만 덧입힌다. 기본 전구는 항상 켜져 있으며 추가 발광만 기존 4패턴을 따른다. 터널 내부 광원은 없다.

오로라는 큰 블러 대신 그라디언트·투명 마스크·transform 애니메이션으로 경계를 부드럽게 한다. 비활성 테마는 숨기고 선택창/비활성 화면에서는 애니메이션을 정지한다. 모션 감소는 정적으로 표시하며 낮은 품질에서는 별 수를 줄인다. 오로라 호수의 원본 그림 속 오로라는 마을 디자인의 일부지만, 별도 움직이는 야간 테마는 해당 이용권이 있어야 적용된다.

사진에는 같은 팔레트의 Canvas 하늘·별·달·눈 반사를 합성한다. 트리/기차는 실제 WebGL 스냅샷을 사용하며 1200×1560 PNG 형식을 유지한다.

## 독립 보상 및 잠금

`nightPasses[themeId]`가 세 테마별 이용권이다. `villagePasses[villageId]`와 공유하지 않는다. SDK의 정상 보상 완료 결과만 해당 대상의 정확한 7일 이용권을 발급하며, 활성 기간은 연장하지 않는다. 취소/실패/시간 초과는 지급하지 않는다. 만료되면 해당 테마만 해제하고 다른 테마·마을의 이용권은 유지한다.

잠긴 카드는 정적 미리보기만 제공하고 누르면 광고 안내를 연다. 메인 장면의 테마/실제 선택은 바꾸지 않으므로 광고 전에 무제한 효과를 이용할 수 없다. 광고를 강제로 시작하지 않는다. 활성 카드는 적용/남은 일수/만료 시각을 표시하고 만료 카드는 재시청 안내를 표시한다. 마을 미리보기와 야간 보상 대상을 혼동하지 않도록 요청 대상도 명시적으로 고정한다.

기존 공유 야간 영수증이 저장돼 있으면 이미 선택했던 테마 한 개에만 원래 만료 시각 그대로 옮긴다. `wishes`는 금색 테마 `shooting`으로 연결한다. 새 영수증 3개를 임의 발급하거나 기간을 새로 연장하지 않는다. 이용권은 기존처럼 로컬 기록이며 서버 인증 영수증이 아니다.

## 검증

- 자동 테스트 40개·TypeScript·웹 빌드·산출물 검사 통과. 7개 마을 1~18바퀴의 기적 판정 및 기존 광고 실패/취소 검사는 유지했다.
- 실제 Chromium Web Audio: 기적 RMS 0.06038294/피크 0.19149007, 주행음 RMS 0.00859615, 음악 RMS 0.10133108, 혼합 피크 0.24038839. 이전 기적 RMS 0.08626134의 70%이며 음악/주행음은 동일하다. 실시간 오디오 그래프도 출력이 확인됐지만 스피커 청감은 미검증이다.
- 320×640·375×812·430×932·430×640에서 이미지 가로 경계·주요 버튼 44px·ON 글자 제거·하단 여백을 검사했다. 플레이어와 메뉴 사이 간격은 각각 약 29/57/74/24px였다. 짧은 430×640에서는 약 3px의 자연스러운 세로 스크롤이 허용된다.
- 잠금 상태 3종 모두 실제 효과 미적용/영수증 미지급/광고 미설정 버튼 비활성 확인. 광고 안내 취소도 실제 선택에 영향을 주지 않았다.
- 활성/만료 UI와 사진 검사는 별도의 임시 브라우저 컨텍스트에 테스트용 영수증 fixture를 주입했다. 제품에 보상 우회 코드를 넣거나 SDK 성공을 위장하지 않았다. 실광고 지급 검증이 아니다.
- 테마 적용→다른 기본 마을 선택→효과 유지→PNG 촬영, 기본 분위기 복귀, 만료 시 효과 해제와 만료 안내를 검사했다. 세 PNG는 모두 1200×1560이다.

## 크기와 실제 기기 확인

비교 기준은 직전 웹 빌드 2,165,494바이트이며 새 CSS/테마 합성/독립 이용권 로직만 늘어난다. 신규 대용량 이미지·음원·라이브러리는 없다. 최종 크기는 2,170,708바이트로 5,214바이트(약 5.2KB, 0.24%) 증가했다. 증가분은 CSS와 테마 합성/이용권 로직이며 이미지 파일 수와 전체 파일 수 23개는 동일하다. AIT를 생성하지 않았으므로 AIT 패키지 크기를 측정했다고 주장하지 않는다.

최신 공식 앱 크기 제한은 확인하지 못했다. 공식 문서 `https://developers-apps-in-toss.toss.im/llms.txt`는 현재 프록시 CONNECT 403으로 차단됐고 설치된 SDK 문서에서도 최신 제한을 확인할 수 없었다. 임의의 MB 한도를 가정하거나 공식 제한 통과로 보고하지 않는다.

광고 그룹 ID가 비어 있어 실제 광고 SDK의 노출/완료/지급, 토스 WebView 안전 영역·성능·네이티브 PNG 저장·물리적 스피커 청감은 미검증이다. 실제 ID를 설정한 뒤 기기에서 확인해야 한다. 광고 중 음악/효과음 정지는 기존 rewardBusy/visibility 경로를 유지한다.
