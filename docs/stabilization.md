# 빌리지 안정화 검증

작업 기준은 `feat/elliptical-train-ride`의 `db353e22f093b71feb6b1e23079f136614ff5728`이다.
main 병합과 AIT 생성은 하지 않는다. 기본 `npm run build`는 웹 전용이며 이를 회귀 테스트로 보호한다.

## 변경

- 음악 별도 종 버퍼·소스·버스 제거. 오르골 악기 배음과 기차 음원은 유지.
- 4번은 빈 score와 명시적 unavailable 설정이 원인이었다. 전통 원선율을 독립 채보해 추가.
- 5번을 Adam의 거룩한 밤으로 교체. 출처와 권리·확인 한계는 [음악 문서](music-rights.md)에 기록.
- 음악 끝 자동 다음 곡 및 저장되는 한 곡 반복 설정. 일시정지·숨김 시 종료 콜백 오작동 방지.
- 버튼 이름 `조명` 고정. gentle 초기값과 all → alternate → random → gentle → off 순환/저장 유지.
- 각 빌리지 원본 셀에서 창문/가로등을 별도로 측정하고 부분 발광/감광. 건물/가로등/트리 그룹 교차.
- 별의 발광 헤일로 및 작은 실제 반사광 추가. 환경광은 OFF에서도 유지.
- 선택 카드는 눈 레이어를 생성하지 않는다. 메뉴가 열리면 메인 눈만 숨기고 멈추며 설정값은 보존.
- 미리보기 배너와 해당 CSS/복귀 버튼 제거. 미리보기 접근 제한·광고 보상/이용권 구조는 유지.
- 차량별 재질의 터널 클리핑 평면을 입구 뒤로 이동하고, 실제 입구 실루엣의 픽셀 단위 가림 추가.
  차량별/차량 내부에서 앞부터 가려진다. 불투명도 전체 변경이나 차량 visible 토글은 쓰지 않는다.
  터널 안 이동 계산·차량 간격·레일 보정·속도는 바꾸지 않는다.
- 기적은 매 간격마다 20~50초 난수를 새로 뽑는다. 주행 정지 시 예약 음원·타이머를 취소하고 새 간격으로 재개.
- 요청된 웹 배포가 변수 미설정으로 건너뛰어지지 않도록 기존 개발 브랜치 전용 Pages job의
  `ENABLE_PAGES` 조건만 제거. main/PR은 배포하지 않는다. AIT 수동 워크플로는 변경하지 않는다.

## 재현

```sh
cd /workspace/merry-village
npm ci
npm run build
npm run dev -- --port 5173 --strictPort
```

별도 쉘에서 선택적 실제 브라우저 회귀를 실행한다. playwright-core는 검증 도구이며 앱 번들에 포함되지 않는다.
이미 설치된 모듈이 있다면 해당 `index.mjs` 절대 경로를 `PLAYWRIGHT_MODULE`에 지정한다.

```sh
npm install --prefix /tmp/merry-browser-tools --no-audit --no-fund playwright-core@1.56.1
PLAYWRIGHT_MODULE=/tmp/merry-browser-tools/node_modules/playwright-core/index.mjs \
  node scripts/check-stability-browser.mjs
```

Chromium 기본 경로는 `/usr/bin/chromium`, 필요 시 `CHROMIUM_PATH`로 지정한다.
결과는 `/tmp/merry-stability/report.json`, 6개 마을 모바일 PNG, 터널 진입/출구 프레임,
실제 다운로드한 `photo.png`이다. `BROWSER_OUTPUT`으로 출력 위치를 바꿀 수 있다.
`scripts/check-polish-browser.mjs`는 최신 검사로 연결한다. 이전의 종 stem 필수/4번 비활성 기대값은 폐기했다.

브라우저 검사는 실제 Web Audio 분석기에서 각 곡의 RMS와 피크를 읽는다.
재생 UI 문구만으로 성공 판정하지 않는다. 오디오 출력의 청감/스피커 품질이나
토스 네이티브 브리지·실제 광고 재생·기기 WebView 성능을 검증한 것으로 간주하지 않는다.
사진은 무료 마을에서 실제 PNG 다운로드를 확인하며 가짜 광고 보상을 지급하지 않는다.

최종 커밋 후 웹 빌드를 다시 생성해 build-info.json의 SHA와 실제 HEAD를 맞춰야 한다.
GitHub API/Pages 도메인 차단 시 원격 Actions/공개 화면의 확인은 로컬 검증과 구분해 보고한다.

## 이 작업의 실제 로컬 결과

- Node.js 24.19.0, TypeScript 검사 통과. 자동 테스트 29개 통과, 실패/건너뜀 0.
- 웹 빌드와 `verify:web` 통과. 외부 리소스 없이 웹 파일 9개 검증.
- Chromium 390×844에서 6개 마을 렌더링, 메뉴 4개, 특별한 밤 3종 선택, PNG 다운로드 확인.

  별도 bells stem 없음, 음악 단독 측정 때 기차 버스는 무음. 재생·일시정지·이전/다음·반복·자동 다음 곡 통과.
- 5단계 조명 순환, 고정 버튼명, 빌리지 변경/새로고침 후 저장 상태 통과.

- 실제 기차 버스 RMS .0169, 실제 기적 RMS .0040 확인. 첫 대기 31.33초,
  재개 후 새 대기 28.19초를 관측. 정지 후 주행음·기적 무음 확인.
- 브라우저 JavaScript/셰이더 오류 0. 사진 파일은 실제 PNG 1200×1560.

사진 저장, 실제 보상 광고는 미검증이다. 이용권/광고 로직은 유지하고 기존 회귀 테스트를 통과했다.
