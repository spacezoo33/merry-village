# 메리빌리지 제품형 미니어처 버전

개발 브랜치 `feat/elliptical-train-ride`, SDK/appName, 기존 Pages 및 웹 ZIP 워크플로 유지. AIT 생성 금지.

## 실제 장면 구성

- 기존 `christmas-room.png`의 촛불·실내 보케·겨울 창문 배경 재사용.
- 새 `product-villages.png`: 고급 원목 받침대, **Merry Christmas** 금속 명판, 유럽 건축물,
  눈 덮인 단차·돌계단·철제 난간·터널·사람·가로등을 담은 6개 정적 제품 플레이트.
  중앙 트리와 기차는 이미지에 포함하지 않는다. 소스 그대로 보존하며 SVG viewport로 각 셀을 표시한다.
- `actors.ts`: Three.js 실제 3D 트리(가지·눈·장식구·리본·전구·별), 기관차 1대와 객차 2대,
  연결 장치와 철로. 평면 사진을 돌리거나 프레임 이미지를 바꿔 회전을 흉내 내는 방식이 아니다.
- 직교 카메라로 실제 원형 지면 경로를 타원으로 투영한다. `kinematics.ts`에서 동일 경로의
  차량 접선 방향과 차량 길이+커플러 길이로 후속 차량의 위치를 계산한다. 시간 지연 방식이 아니다.
- 트리 37초 Y축 회전, 열차 18초 순환(0.65초 출발 지연). 공통 동작 버튼으로 중단 위치에서 재개.
  별도 시간식으로 움직이며 음악과 독립적이다. 뒤쪽 선로는 마을/터널 내부 구간으로 월드 좌표 클리핑한다.
- 조명: 각 전구는 별도 위상/색으로 완만하게 밝기가 변하며 트리와 함께 회전한다.
  OFF 시 실제 3D 발광과 건물 추가 발광 레이어를 끈다. **정적 이미지의 창문과 가로등에 기록된 따뜻한 빛은 남는다.**
  건물 전체가 실시간 3D 조명을 받는 것은 아니다.
- 눈: 작은 입자 24개, 전경/후경 크기·속도 차이. OFF 즉시 제거.
- 오른쪽 동작/조명/눈 3개만 표시. 상단 로고·설명·밤 전환 버튼 제거.
- 하단 빌리지/음악 선택/특별한 밤/사진 촬영 및 다크 브라운 음악 플레이어.

## 빌리지와 효과

무료 3종: 시계탑 마을 / 숲속 샬레 / 성당 마을.
특별 3종: 선물 공방 / 겨울 궁전 / 진저브레드 목조 시장. 다른 건축물의 6개 제품 플레이트다.
모두 같은 실제 3D 트리·연결 열차를 사용하며 동작/조명/눈 설정을 유지한다.
잠긴 콘텐츠는 명시적인 미리보기이며 저장된 선택/이용권을 바꾸지 않고 사진 저장을 차단한다.

특별한 밤은 오로라(초록·보라 흐름), 별빛(반짝이는 별과 내려오는 금빛 입자), 황금빛(건축 조명 발광 강화)이다.
황금빛 밤은 장식 조명 OFF 시 발광하지 않는다. 단순 전체 화면 어둡게 하기나 낮밤 버튼은 없다.

## 음악과 사진

[음악 권리 문서](music-rights.md)의 공개 악보 5곡을 자체 Web Audio 합성으로 연주한다.
외부 녹음물은 없다. 실제 시간/전체 시간/진행 막대/이전·재생·다음/반복/자동재생 시도와 터치 재시도 지원.

사진은 1200×1560 PNG. 배경·현재 마을 플레이트·촬영 시점의 WebGL 프레임(트리/열차 위치),
조명 설정·눈·특별한 밤 효과를 전용 구도로 합성한다. UI/플레이어/앱 제목은 포함하지 않는다.
입자와 오로라는 사진용으로 다시 그리므로 화면의 모든 입자 위치까지 동일한 픽셀 복제는 아니다.
웹 다운로드 및 공식 SDK `File.saveBase64` 경로 유지. 네이티브 저장은 토스 실기기에서 미검증.

## 광고와 이용권

기존 정책인 보상형 광고 완료 1회 → 특별 빌리지 3종+특별한 밤 3종 7일 이용권, 기간 누적 없음/만료 후 재시청 유지.
`loadFullScreenAd`/`showFullScreenAd`의 `userEarnedReward` 확인에만 지급한다.
현재 `public/runtime-config.json`의 실제 광고 그룹 ID가 비어 있어 **실광고·실제 보상 지급은 미완료**다.
웹과 개발 모드에서 광고 완료를 흉내 내거나 무료 이용권을 지급하지 않는다. 무료 기능에 광고/배너 없음.
영수증은 기기 로컬 저장이며 서버 검증·계정 동기화·변조 방지는 미구현이다.

## 성능과 한계

3D는 30fps 상한, DPR 최대 1.75, 저전력 GPU 선호, 인스턴싱, 화면 크기에 맞는 리사이즈를 사용한다.
탭/광고 백그라운드 시 중단하며 움직임 줄이기에서는 정지된 트리·기차·효과를 표시한다.
WebGL2 미지원 기기에는 동작을 표시할 수 없음을 안내하며 동작 버튼을 비활성화한다.
Three.js(MIT) 추가는 실제 수직축 회전과 연결 열차의 원근감을 위한 것이다.

이 버전은 **사진형 정적 건축물 + 직접 모델링한 3D 트리·열차**의 혼합이다.
참조 이미지와 같은 모든 오브젝트의 완전한 3D 모델/재질은 아니다. 건물·터널의 개별 교체나 완전한 동적 그림자,
사진급 전문 3D 트리/열차 모델, 건물의 완전한 소등을 위해서는 분리된 고해상도 모델·재질·비발광 건축 에셋이 추가로 필요하다.
기존 4개 PNG와 이전 도형/레이아웃 소스는 삭제하지 않고 보존했다. 현재 웹은 신규 제품 플레이트와 기존 배경만 번들한다.

## 확인 방법

`npm run build`는 TypeScript → 자동 테스트 → 웹 빌드 → appName/파일/소스 커밋 검증만 수행한다.
브라우저에서 320/375/430px 및 PC, 동작 중단/재개, 장면 전환, 음악/효과, PNG 다운로드와 움직임 줄이기를 검사한다.
Pages: https://spacezoo33.github.io/merry-village/ . 실제 배포 완료 여부는 Actions의 해당 커밋 `Build web preview` → `pages`에서 확인한다.
