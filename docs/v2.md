# 메리빌리지 2.0 구현 현황

이번 대화의 요구사항을 기준으로 기본 명칭/콘셉트를 구성했습니다. 별도의 통합 기획 전문과 광고 그룹 ID는 제공되지 않았습니다. 기존 Pages 워크플로, 개발 브랜치 `feat/elliptical-train-ride`, SDK 설정과 appName을 유지합니다. AIT는 생성하지 않습니다.

## 실제 구현

하단 메뉴는 **빌리지 / 음악 선택 / 특별한 밤 / 사진 촬영**입니다. 기존 기차·트리·산타·눈사람·마을 개별 선택/강조 기능은 제거했습니다. 기차는 장면의 정적인 소품일 뿐 주행하지 않습니다.

| 구분 | 이름 | 실제 구성 |
| --- | --- | --- |
| 무료 | 포근한 크리스마스 | 기존 마을, 트리·집·성당·산타·기차 |
| 무료 | 눈꽃 숲속 마을 | 소나무 숲, 작은 집·트리·루돌프·눈사람 |
| 무료 | 종소리 작은 성당 | 큰 성당, 집 두 채·작은 트리·숲 |
| 특별 | 산타의 선물 공방 | 새 공방 이미지, 산타·선물 기차·소나무 |
| 특별 | 달빛 겨울 궁전 | 새 얼음 궁전 이미지, 트리·루돌프·눈사람 |
| 특별 | 진저브레드 마을 | 새 과자집 이미지 세 채, 산타·트리·눈사람 |

각 마을은 다른 오브젝트 구성을 사용하며 단순 색상 필터 6종이 아닙니다. 무료 3종은 즉시 사용합니다. 특별 콘텐츠는 이용권이 없으면 **미리보기**라고 명시하며 선택/효과를 영구 저장하거나 사진으로 저장하지 않습니다. 돌아가기로 기존 무료 선택으로 복귀합니다.

음악 5곡은 외부 MP3 대신 Web Audio로 실제 합성 연주하는 짧은 오리지널 오르골 멜로디입니다. 기존 상업 음원이나 녹음곡을 제공한다고 주장하지 않습니다.

1. 눈 내리는 작은 마을
2. 별빛 산책
3. 선물 공방의 왈츠
4. 겨울 숲 자장가
5. 크리스마스 편지

자동 재생을 시도하지만 브라우저 정책으로 차단되면 실제 재생 중이라고 표시하지 않고 재생 버튼을 안내합니다. 곡 선택·반복·음량·일시정지/재개, 탭이 숨겨졌을 때 중단을 지원합니다. 페이지를 다시 열면 선택한 곡/음량을 복원하고 재생을 다시 시도합니다.

특별한 밤은 **오로라의 밤 / 별똥별의 밤 / 소원을 띄우는 밤**입니다. CSS 조명/입자 효과이며 움직임 줄이기에서는 정지된 효과를 표시합니다. 눈 켜기/끄기와 낮/밤 전환을 지원합니다. 낮으로 바꾸면 선택한 밤 효과를 해제합니다.

사진 촬영은 기기 카메라를 켜는 기능이 아니라 **현재 마을을 전용 구도의 1200×1560 PNG로 합성**하는 기능입니다. UI 버튼은 제외합니다. 동일한 이미지/레이아웃 데이터를 재사용하며 사진 프레임의 제목과 마을명을 넣습니다. 웹에서는 실제 PNG 다운로드, 지원되는 토스 앱에서는 공식 `File.saveBase64`로 저장하도록 연결했습니다. 토스 네이티브 저장은 실기기 미검증입니다.

## 7일 이용권과 광고: 구현/미완료 구분

구현된 흐름:

- 특별 빌리지 3종 + 특별한 밤 3종 + 특별 장면 사진 저장을 한 이용권으로 7일간 이용합니다.
- 공식 SDK 3.9.0의 `loadFullScreenAd`, `showFullScreenAd`, `isSupported()`를 사용합니다.
- `userEarnedReward` 이벤트가 확인된 세션에만 지급합니다. 광고 종료/세션 정리 시 보상 여부를 확정합니다. 단순 노출/클릭/닫기/실패로는 지급하지 않습니다. 중복 콜백은 한 번만 처리합니다.
- 로딩/시청 시간 제한, 실패 안내, 중복 요청 방지, 구독 정리를 구현했습니다.
- 개발 mock, 일반 웹, 누락된 광고 ID에서는 광고를 본 것처럼 처리하거나 이용권을 발급하지 않습니다.
- 이용권은 지급 시각부터 정확히 7×24시간이며 추가 누적하지 않습니다. 유효 이용권이 있으면 광고 재시청을 요청하지 않습니다.
- 만료되면 특별 마을/밤을 해제하고 기본 무료 마을로 돌아갑니다. 창 재진입과 주기적 검사에서 갱신합니다.

**아직 미완료:** 실제 광고 그룹 ID 등록, 토스 실기기 광고 시청/보상 확인, 서버 기반 이용권 검증 및 계정/기기 간 동기화.

현재 `public/runtime-config.json`의 `rewardedAdGroupId`는 빈 문자열입니다. 따라서 실제 광고 버튼은 ‘광고 연결 준비 중’으로 비활성화됩니다. 이 상태에서 이용권 지급이 된다고 주장하지 않습니다. 운영 광고 ID를 발급받으면 해당 필드에 **보상형 광고 그룹 ID**를 넣습니다. 이 ID는 공개 설정이며 API Secret/비밀키를 넣어서는 안 됩니다. Pages 설정을 바꿀 필요는 없습니다.

이용권/설정은 현재 기기의 localStorage에 저장됩니다. 저장소 삭제·재설치·기기 변경 시 복구하지 못합니다. 클라이언트 시각/저장소는 사용자가 바꿀 수 있으므로, 현재 구현은 서버에서 위변조를 검증하는 운영 권한 시스템이 아닙니다. 저장이 차단되면 이번 화면에서만 유지된다는 안내를 표시합니다. 운영 수준의 부정 이용 방지는 별도 서버 검증이 필요합니다.

## 에셋 상태

기존 `miniature-atlas.png`, `christmas-room.png`를 6종에 공통 재사용합니다. 미사용 `train-directions.png`도 원본을 보존합니다. 새 `special-buildings.png`는 이 프로젝트용으로 생성한 투명 아틀라스이며 공방·얼음 궁전·과자집의 개별 이미지입니다. 현재 6종을 표시하는 데 누락된 이미지는 없습니다.

음악은 합성 악기이므로 녹음/마스터링된 음원 파일은 제공하지 않습니다. 물리적인 3D 조명, 기차 주행, 개별 장식품 교체, 서버 계정 기능은 구현하지 않았습니다.

## 검증

- `npm run build`: TypeScript, 16개 자동 테스트, 웹 빌드와 웹 파일 검증. AIT 없음.
- 자동 테스트: 6개 레이아웃/무료·특별 분류/5곡, 저장 데이터 복원·오류, 7일 경계·만료, 광고 실패·중복·보상 이벤트, 기존 웹/CI 정책.
- 실제 Chromium: 320/375/430px와 PC, 4개 메뉴, 6개 장면과 잠금 미리보기, 실제 AudioContext/오실레이터 재생·일시정지·곡 변경·음량, 3개 밤과 모션 감소, PNG 생성·실제 다운로드, 설정 복원과 이용권 만료 처리.
- 이용권 유효/만료 UI 검증은 브라우저 테스트용 저장 데이터로 확인했으며 실제 광고 시청 성공으로 보고하지 않습니다. 테스트 데이터는 검증 후 제거합니다.
- 토스 앱 실기기, 실광고, 네이티브 사진 저장, 최신 GitHub Actions/Pages 실행 결과는 별도 확인 사항입니다.
